# Подсчёт ненулевых элементов двух матриц

Консольное приложение на C++, предназначенное для вычисления количества ненулевых элементов в двух пользовательских матрицах $F$ и $G$ одинаковой размерности.

\---

## Описание

Программа принимает с клавиатуры (стандартный поток ввода `std::cin`) размеры двух прямоугольных матриц `F` и `G`, а затем их числовые элементы (тип `double`). После считывания данных производится подсчёт элементов, отличных от `0.0`, и вывод итоговых значений на экран.

\---

## Принцип работы

1. **Ввод размерностей:** Пользователь задаёт количество столбцов (`countOfColoumn`) и строк (`countOfRow`).
2. **Выделение памяти:** Матрицы представляются в виде двумерных динамических массивов `std::vector<std::vector<double>>`. Размеры задаются с помощью метода `.resize()`.
3. **Чтение элементов:** Программа последовательно считывает элементы сначала для матрицы `F`, затем для матрицы `G`.
4. **Подсчёт ненулевых элементов:** Функция `getNonZeroCount` обходит элементы переданной матрицы и суммирует количество значений, не равных `0.0`.
5. **Вывод результатов:** Количество ненулевых элементов для каждой матрицы выводится в консоль.

\---

## Формат ввода и вывода

### Формат ввода

1. Первая строка: два целых положительных числа — количество столбцов и строк.
2. Последующие строки: $2 \\times (\\text{столбцы} \\times \\text{строки})$ вещественных чисел:

   * сначала все элементы матрицы `F` (построчно);
   * затем все элементы матрицы `G` (построчно).

### Формат вывода

* При корректном вводе:

```text
  Count of noZero elements of the first matrix: <число>
  Count of noZero elements of the second matrix: <число>
  ```

* При ошибке ввода:

```text
  INVALID
  ```

\---

## Примеры работы

### Корректные данные

**Входные данные:**

```text
2 3
1 0 2 0 0 3
4 5 6 0 0 0
```

**Вывод программы:**

```text
Count of noZero elements of the first matrix: 3
Count of noZero elements of the second matrix: 3
```

*Пояснение:*

* Размер матрицы: 2 столбца, 3 строки (всего $2 \\times 3 = 6$ элементов).
* Матрица $F$: элементы `1, 0, 2, 0, 0, 3` $\\rightarrow$ 3 ненулевых элемента (`1`, `2`, `3`).
* Матрица $G$: элементы `4, 5, 6, 0, 0, 0` $\\rightarrow$ 3 ненулевых элемента (`4`, `5`, `6`).

\---

### Некорректный ввод

Если переданы отрицательные размеры, нулевые размеры или нечисловые символы:

**Входные данные:**

```text
-2 3
```

или

```text
2 abc
```

**Вывод программы:**

```text
INVALID
```
