# \# Подсчёт ненулевых элементов двух матриц

# 

# Консольная программа на C++, которая вводит с клавиатуры две матрицы `F` и `G`

# одинакового размера и выводит количество ненулевых элементов в каждой из них.

# 

# \## Как это работает

# 

# 1\. Программа запрашивает количество столбцов (`countOfColoumn`) и строк (`countOfRow`).

# 2\. Матрицы хранятся как `std::vector<std::vector<double>>`; память под элементы

# &#x20;  выделяется с помощью `resize`.

# 3\. Элементы матриц `F` и `G` последовательно считываются из стандартного потока ввода.

# 4\. Функция `getNonZeroCount` проходит по всем элементам матрицы и считает те,

# &#x20;  что не равны `0.0`.

# 5\. Результаты для обеих матриц выводятся на экран.

# 

# При некорректном вводе (нечисловое значение или отрицательный размер)

# программа печатает `INVALID` и завершается.

# 

# \## Пример работы

# 

# Ввод:

# 2 3

# 1 0 2 0 0 3

# 4 5 6 0 0 0

# 

# Вывод:

# Count of noZero elements of the first matrix: 3

# Count of noZero elements of the second matrix: 3

#
